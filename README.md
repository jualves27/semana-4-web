# semana-4-web
JavaScript Prático: Arrays, DOM e Eventos

Exercícios práticos para consolidação de conceitos essenciais de JavaScript, divididos em três partes:

 Conteúdo

1. Bloco 1 – Arrays e Métodos (`map`, `filter`, `reduce`, `forEach`): Manipulação e transformação de dados, filtragem e cálculo de acumuladores em arrays e objetos.
2. Bloco 2 – Manipulação do DOM: Criação dinâmica de elementos (`createElement`), modificação de classes CSS (`classList`) e contagem de itens na página.
3. Bloco 3 – Eventos e Event Delegation: Interações com o utilizador (`click`, `mouseover`, `keyup`), submissão de formulários com `preventDefault()` e otimização de eventos com Event Delegation.

 Como Executar

1. Abre o ficheiro `index.html` em qualquer navegador para interagir com a lista e os eventos.
2. Abre a Consola do Programador (`F12` ou `Ctrl + Shift + I`) para visualizar os outputs dos métodos de arrays e DOM.
